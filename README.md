# 🎓 EduPro Analytics

EduPro Analytics is a Streamlit-based data analytics and predictive intelligence platform for an online learning platform.

## 📌 Project Overview

The project analyzes historical EduPro data to understand course, teacher, revenue, and user performance. It also uses machine learning to predict future course enrollments and revenue.

## 🚀 Features

- 📊 Interactive Analytics Dashboard
- 📚 Course Analysis
- 👨‍🏫 Teacher Analysis
- 💰 Revenue Analysis
- 👤 User Analysis
- 🤖 AI-based Enrollment Prediction
- 💵 Course Revenue Prediction
- 📈 Business Insights
- 🔍 Interactive Filters
- 📥 Data Export

## 🤖 Machine Learning

The project compares:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Random Forest Regressor
- Gradient Boosting Regressor

### Prediction Targets

- Course Enrollment Count
- Course Revenue

### Evaluation Metrics

- MAE
- RMSE
- R² Score
